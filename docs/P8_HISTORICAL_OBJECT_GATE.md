# P8 | Historical mechanical object applicability gate (design only)

## Candidate category: waterwheel transmission

**Status: SOURCE_GAP / SCHEMATIC_ONLY. No historical reconstruction produced.** The category is an illustration of the method, not a claim about a particular Chinese or European artifact.

### Required evidence before any named object is rendered

1. Identify precisely one object, archaeological or museum record, and stable catalog/inventory/source locator. When available, document fieldwork coordinate/method, photography date, collection and object chronology.
2. Separate measured wheel diameter, blade dimensions, axle and gear material from *estimated* properties. Preserve each source's figure/page number. If a measurement has no source, display `UNKNOWN`, not a realistic guessed number.
3. Where multiple contemporary illustrations disagree, show alternative interpretations and explain why; use distinct evidence-strength tags.
4. Show kinematic arrows only when documented geometry or mechanical constraints support that transmission. If motion is a modern idealization, label `ILLUSTRATIVE`.
5. Include at least one possible counter-evidence item, e.g. a reverse-side photograph could invalidate the inferred power takeoff route, or a measurement could falsify the inferred ratio.
6. Avoid adding color, surface texture or realistic wear to unobserved parts in a way that implies authenticity.

### Acceptance gates

- `IDENTIFIED_OBJECT`: not met.
- `DATING_AND_PROVENANCE`: not met.
- `DIMENSIONAL_DATA`: not met.
- `KINEMATIC_ATTESTATION`: not met.
- `PUBLIC_VISUAL_RECONSTRUCTION`: **BLOCKED pending all above**.
- `GENERAL_PRINCIPLE_DIAGRAM`: feasible, if clearly labeled pedagogical.

### Lessons transferred from B-tree

An accessible provenance panel and mechanical animation are not themselves evidence that geometry is correct. The model must expose assumptions and uncertainties without overriding observations. A historically-specific drawing needs a cataloged source, not an illustrative animation copied from the Internet.
