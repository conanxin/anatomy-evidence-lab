# P10 桔槔版本溯源与历史图版门槛
日期：2026-10-18。这个项目只演示已描述的机械原理，并非特定文物的原状复原。
- [《庄子·天地》](https://ctext.org/text.pl?if=en&node=2795&remap=gb&show=parallel)：后重前轻叙述，非图像。
- [《王祯农书》卷十八文字](https://zh.wikisource.org/w/index.php?title=王禎農書/卷十八&oldid=1142890)：桔槔俯仰、辘轳圆转，现代转录且部分引述《庄子》，不是独立测量。
- [CTP《钦定四库全书》本《农书》影印分册](https://ctext.org/library.pl?if=gb&remap=gb&res=5434)：浙江大学图书馆、CADAL扫描；已定位卷十七～十八分册，尚未取得具体桔槔叶面。
- [北京故宫《农书》](https://www.dpm.org.cn/ancient/hall/151496.html)：1776年武英殿聚珍版，16册2函；馆藏目录并非已经获取原叶。
- [识典《三才图会》“桔𫽿”条目](https://www.shidianguji.com/zh/book/HY7188/chapter/1m6m51x69yo8k)：器用十卷之独立图文条目；不能由此确定馆藏的同版页码。
- [台北故宫1609年《三才图会》刊本目录](https://rarebooks-maps.npm.edu.tw/index.php?act=Display%2Fimage%2F130834lC-o%3Dwp)：贈善004931–005023共93册，页面注明“本部尚未数字化”。
- [中国节水网2022年转载图](https://www.waterconserving.cn/universal/detail/6165)：图注标为《三才图会》桔槔插画，未明确原叶和馆藏底本，属二手出处。
- [国博《农书》介绍](https://www.chnmuseum.cn/zp/zpml/gjwxbt/202203/t20220301_254053.shtml)：元代王祯及1313年刊印的历史背景，不能倒推今日每张传世图来自元刊。
结论：七条来源线索、**零张已核实原刊桔槔叶面**。下次需证明馆藏、版刻年代、册卷、具体叶码、原图稳定链接及图像/来源版本一致性，才可升级几何复原的证据等级。
